# fw-aes: a multi-view HLS demo

AES-128/256 built through the views of the multi-view HLS flow, from an
untimed model (V0) to scheduled stage-level TLM (V3), lowered RTL (V5) and
ECP5 synthesis, with a built-in DMA variant, contracts, a co-synthesis pass,
and a comparison of standalone and integrated DMA configurations.
